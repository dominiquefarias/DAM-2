Acceso a datos es una asignatura aparte (la da Vicente)

Los datos de una empresa pueden venir de muchos sitios:

Archivos y ficheros
-por ejemplo un montón de PDF, CSV, hojas de cálculo

Conectores a bases de datos que ya existen
-MySQL

Mapeo objeto-relacional
-orientadas a objetos, XML, JSON

Bases de datos documentales
-JSON (MongoDB)
